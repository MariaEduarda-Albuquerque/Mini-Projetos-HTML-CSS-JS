# Mini-Projetos HTML, CSS e JS
Repositório de mini-projetos front-end desenvolvidos com HTML, CSS e JavaScript durante meus estudos, organizados por pasta para facilitar navegação e demonstração.
## Sobre o repositório
Este repositório reúne pequenos projetos práticos de front-end, com foco em:
- Praticar manipulação do DOM e lógica em JavaScript
- Aplicar conceitos de HTML semântico e estilização com CSS
- Manter um portfólio organizado de estudo e evolução
---
## Estrutura do Repositório
| Pasta | Conteúdo |
|---|---|
| `Calculadora-soma/` | Calculadora simples para realizar operações de soma, desenvolvida com HTML, CSS e JavaScript |
---
## Como executar os programas
**Pré-requisito:** navegador atualizado (Chrome, Firefox, Edge, etc.).
```bash
# 1. Clone o repositório
git clone https://github.com/MariaEduarda-Albuquerque/Mini-Projetos-HTML-CSS-JS.git
# 2. Acesse a pasta do projeto desejado
cd Calculadora-soma
# 3. Abra o arquivo index.html no navegador
```
