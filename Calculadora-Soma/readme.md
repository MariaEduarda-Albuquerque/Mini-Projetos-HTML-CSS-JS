# Calculadora de Soma

Projeto simples de uma **calculadora de soma**, desenvolvido com **HTML, CSS e JavaScript**, com foco no aprendizado de lógica básica.

🔗 [**Ver demonstração online**](https://mariaeduarda-albuquerque.github.io/Mini-Projetos-HTML-CSS-JS/Calculadora-soma/)

## Funcionalidades

* Inserção de dois valores numéricos
* Cálculo automático da soma
* Exibição do resultado na tela
* Validação para aceitar apenas números

## Como usar

1. Abra o arquivo `index.html` no navegador
2. Digite dois números nos campos indicados
3. Clique no botão **Somar**
4. O resultado será exibido logo abaixo

## Objetivo do projeto

Este projeto foi criado com fins **educacionais**, para praticar:

* Eventos em JavaScript
* Manipulação de elementos HTML
* Validação de entrada de dados
